# Правила для агентов, работающих с каталогом API

Цель репозитория — поддерживать публичный каталог маршрутов Wildberries, Ozon и Яндекс Маркета по адресу https://github.com/x-mp/marketplace-api-routes.

## Поддержание актуальности

- При каждой задаче, связанной с изменением API, проверяйте официальную документацию и более свежие спецификации затронутого маркетплейса. При регулярном обслуживании проверяйте источники не реже одного раза в месяц. Само наличие этого правила не запускает проверку автоматически.
- Если маршруты, домены, HTTP-методы или признаки устаревания изменились, обновите закреплённый источник и его дату в соответствующем скрипте, пересоберите JSON и CSV затронутого маркетплейса и обновите таблицу дат и количеств в README.md.
- Для WB используйте `scripts/build_wb.py`; для Ozon и Яндекс Маркета — `scripts/build_others.py`. Фиксируйте точный commit источника. Для WB и Ozon сторонние зеркала не считаются подтверждением текущего состояния официального API.
- Дату сборки отличайте от даты исходной спецификации и от даты живой проверки. Не называйте маршрут актуальным только потому, что он есть в снимке. Если официальный источник недоступен, сохраняйте явную пометку `not_live_verified` и объясняйте ограничение в README.md.
- Перед публикацией проверьте, что JSON читается, количество маршрутов совпадает с таблицей README.md, у маршрутов есть корректные HTTPS-адреса, а CSV соответствует JSON. Достаточно одного основного сценария проверки и критических проверок изменённой части.
- Изменения в каталоге завершайте commit и push в `x-mp/marketplace-api-routes`, затем прочитайте опубликованные файлы с GitHub и убедитесь, что нужная версия доступна. Если push невозможен, явно сообщите о препятствии; локальный commit не считайте опубликованным результатом.
- Не публикуйте API-ключи, токены и данные кабинетов продавцов.
